# Agent Time 0.2.0-beta.58

Agent Time prepares credited periods in the background as evidence is ingested. Tool starts and ends are reconciled conservatively; late events, attribution corrections and changed dependencies rebuild affected periods. Original proof events, timing rules, billing policies, manual decisions and saved reports are preserved.

First reports can read persistent prepared periods without replaying the complete history. On an isolated 1.60-million-event history, a 30-day report improved from 43.64 seconds to 136 milliseconds, with peak report memory reduced from 1,070 to 136 MiB and identical complete results. The initial historical preparation took 79 seconds in the background; reports retain the original calculation while preparation is incomplete or unavailable. These measurements are fixture-specific, not a guarantee for every Mac.

Home uses compact responses, a bounded daily cache and details loaded on demand. Review and billing retain validated reading models across restarts. Monthly reports process bounded daily inputs and keep real progress feedback. Lossless context sharing reduces repeated stored payloads without removing proofs.

Background preparation is resumable, storage-budget aware and independent of proof capture. Low capacity, corrupted or outdated derived data fall back safely; the optional tool index reserves space for credited periods. Original history is not deleted by this optimization.
